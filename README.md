# Fysik 1 - Newtons lagar

## Om projektet

Denna hemsida handlar om fysik med fokus på Newtons tre lagar och hur fysik används i samhället.

## Innehåll

- Startsida med introduktion till fysik
- Fördjupning i Newtons lagar
- Fysik i samhället med exempel
- Quiz för att testa kunskap

## Funktioner

- Interaktiv quiz med JavaScript
- Responsiv design för mobil och dator
- Navigation mellan sidor
- Säker hantering av användarinmatning (XSS-skydd)

## Tester

Hemsidan har testats i:

- Google Chrome
- Microsoft Edge
- Mobilvy (responsiv design)

## Bilder

Exempel från Newtons vagga används för att visa rörelse och energiöverföring.

## Teknik

- HTML
- CSS
- JavaScript
